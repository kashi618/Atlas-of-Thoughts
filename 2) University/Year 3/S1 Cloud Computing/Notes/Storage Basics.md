## Primary Storage
Storage that is directly accessible by a computer's CPU. It holds data and istructions that the CPU is activelly using/processing.
- Extremely fast access speedcs
- Volatile
- Limited capacity
- Expensive

**Examples**
- RAM
- Cache memory
- ROM

## Secondary Storage
Non-volatile memory that is not directly accessible by the CPU. Instead, data must first be loaded from secondary storage into primary storage, such as RAM, before the CPU can process it
- Slower access speeds
- Non-volatile
- Large capacity
- Cheap

**Examples**
- SSDs
- HDDs
- USB Drives
