## What is a Virtual Machine
"A completely isolated guest operating system installation within a normal host operating system"
The guest OS is unaware of the virtual environment, and runs as though it has native access to the computer's hardware
![[Pasted image 20261020235812.png]]

**Examples:**
- The JVM (Java Virtual Machine) is an example of a software based virtual machine, allowing java code to execute portably across various hardware and OS's
