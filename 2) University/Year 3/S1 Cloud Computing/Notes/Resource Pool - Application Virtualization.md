It is the technique of presenting an application ot an end user without any installation, or dependencies on the underlying computing platform
- Allows applications to be delivered in an isolated environment
- Ensures integrity of OS and applications
- Aggregates OS resources and the application into a virtualized container for each user
- Avoids conflicts between different applications or different versions of the same application
