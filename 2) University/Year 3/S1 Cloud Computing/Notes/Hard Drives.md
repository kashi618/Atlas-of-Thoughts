## Components
- The hard drive - basic physical disk spinning storage device
- Made of components such as platters, heads, cylinders, and tracks
- LBA (Logical block addresing) address the sectors within the disk. Modern drives have 4 kb sectors
- File systems arrange files into sectors, so that data can be easily stored and retrieved
- Clusters of blocks can be dealt with, using a file allocation table to map a file to the sectors
