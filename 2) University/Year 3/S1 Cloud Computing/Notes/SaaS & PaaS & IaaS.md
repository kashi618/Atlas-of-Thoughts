## SaaS - Software as a Service
All user needs is a browser, and they can access the service
- Gmail, Youtube, office 365, etc
- No need for updates, or downloading/installing

## PaaS - Platfom as a Service
Complete cloud-based proprietary development and deployment environment for building software without the need for managing servers
- Microsoft Azure App, Amazon Web Services, Google App Engine
- Pay per use
- Vendor Lock in. Due to being a proprietary service, the cost of moving to another vendor is pricey. 

## IaaS - Infrastructure as a Service
The basic building blocks of virtualized hardware, including servesr, storage, and networking.
- Microsoft Azure Virtual Machines, Amazon Web Services EC2
- It is the physical hardware that is the service.
- You write/manage the OS, data, and applications
