## Functional Requirements
Functional requirements define what a system should do, such as:
- "Send an email"
- "Process a payment"
- "Retrieve user profiles"

## Non-Functional Requirements - NFR
Non-functional requirements define how the system performs these functions.

There are however, certain requirements that are common across distributed systems:
1) Resource Sharing - Sharing hardware, software, and data
2) Openness - Integrate and evolve through well defined interfaces
3) Concurrency - Coordinate simultaneous access to shared resources
4) Scalability - Handle growth without fundamental redesign
5) Fault Tolerance - Continue service, despite component failures
6) Transparency - Hide unnecessary distribution complexity
