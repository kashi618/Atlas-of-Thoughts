## Consumer's Perspective
### Security and Regulation
- Consumers are indecisive to transfer control of sensitive data
- Regulations may prevent organizations to use cloud services

### Network Latency
- Real time applications may suffer due to network latency and limited bandwidth
 
### Supportability
- Legacy or custom applications may not be compatible with the cloud platform

### Interoperability
- Lack of standardization across cloud based platforms

## Provider's Perspective
### Service Warranty and Service Cost
- Resources must be kept ready at all times, to meet unpredictable demand
- Heft penalty if SLAs (service level agreements) are not fulfilled. These are a formal contract detailing the expected level of service, uptime guarantees, performance metrics etc, between a provider and a consumer

### Huge Numbers of Software to Manage
- Huge number of applications and platform software to purchase from
- ROI (return on investment) is unpredictable. May be too expensive in the long run

### No Standard Cloud Access Interface
- Cloud customers want open APIs
- Need agreement among cloud providers for standardization, as each cloud provider does it differently in their own way
