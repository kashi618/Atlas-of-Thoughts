Technology which enables the detachment of the user state, the OS, and the applications from endpoint devices

Basically:
- It allows organizations to host and centrally manage desktops
- Each desktop are ran as VMs inside of the VDC
- Endpoint devices can be thin clients or PCs, which access the desktops

## Virtual Desktop Infrastructure
![[Pasted image 20261021014548.png]]
Consists of:
- Endpoint devices
- VM Execution servers
- Connection brokers
- Shared storage

### Connection Broker
The connection broker is responsible for establishing and managing the connection between endpoint and desktop VM
