## Compute Virtualisation
A technique of masking or abstracting the physical compute hardware, enabling multiple systems to run concurrently on a single or clustered machine
- Allows the creation of multiple VMs, each running an OS and an application
- Virtualisation layer resides between the hardware and VMs

### Benefits
- Server consolidation
- Isolation
- Encapsulation
- Hardware independance
- Reduced cost
