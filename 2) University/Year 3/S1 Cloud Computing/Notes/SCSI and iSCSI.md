## SCSI
Small Computer System Interface. It is a means of attaching additional storage to a computer. For example, a RAID controller is a SCSI device, allowing connection to an external storage enclosure, with multiple drives

## iSCI
Internet SCSI. Another approach to offering storage on a network. Instead of using file protocols to communicate across a TCP/IP network, SCSI commands are encapsulated in TCP/IP packets itself
