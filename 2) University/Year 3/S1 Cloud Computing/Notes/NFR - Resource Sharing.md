## Resource Sharing in Distributed Systems
In a distributed system, hardware and data resources are shared across the system

**Pros**
It is cost effective to share expensive resources, such as CPU for each system. Compared to buying a new CPU for each system

**Cons**
Security issues can arise from many users accessing common resources at the same time
