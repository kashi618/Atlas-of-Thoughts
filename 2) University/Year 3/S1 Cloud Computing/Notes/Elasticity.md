## Elasticity
Implemented using auto scaling, and is the degree to which a system is able to adapt to workload changes, by provisioning & deprovisioning resources in an automated mammer, so that available resources match the demand

## Elasticity vs Scalability
Scalability is the manual method to provision/deprovision resources depending on workflow. Elasticity is the automated version of this
