## VMDK
This is an open format developed by VMWare, and is the most common format.
It is used by Oracle VirtualBox

## VHD
A native format from microsoft

## VHDX
A next generation upgraded VHD, that supports:
- Up to 64TB disk limit, compared to VHD's 2TB limit
- Large block sizes
- Protects against file corruption
- Conversion between VHD and VHDX is possible, if under 2TB

## AVHD
A VHD differencing disk

## AVHDX
A VHDX differencing disk

## OVF
This specification provides the means to describe the configuration/properties of a virtual system
- XML based format
- Supports extendibility

## OVA
An OVF file, that is also packed togethor with all its supporting files:
- Such as the disk images, etc

It is an all in one
