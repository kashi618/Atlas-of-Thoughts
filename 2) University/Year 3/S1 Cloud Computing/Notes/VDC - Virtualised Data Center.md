## Why?
It transforms a traditional rigid data center, into a flexible highly efficient one by virtualizing its core elements
- **Resource optimisation** - Instead of dedicated physical servers to single applications, a VDC can use hypervisors to run multiple VMs on a single machine
- **Flexibility** - Administrators can quickly add/allocate new virtual machines as needed
- **Cost reduction** - A single server can host multiple applications, removing the need to use a single server for a single application
