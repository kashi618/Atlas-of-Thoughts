## Desktop Virtualisation
![[Pasted image 20261021000155.png]]
It is a technology that enables the detachment of the user state, the OS, and the applications from endpoint devices
- It allows organizations to host and centrally manage desktops
	- Desktops run as VMs within the data centre, which can then be accessed over a network
- These desktops  can be accessed with thin clients, improving security and simplified maintenance

## Network Virtualisation
When multiple virtual networks run independently over a shared physical network
![[Pasted image 20261021001611.png]]

## Infrastructure Virtualisation
Provides a layer of abstraction between hardware and applications, to fix issues such as:
- Server consolidation - eliminating server sprawl by deploying systems as virtual machines, increasing utilization rates from 5-15% to 60-80%
- Test and development optimisation
  By reusing pre-configured systems, testing and developing become standardized
- Business continuity
  Encapsulating entire systems into single files for easy replication, backup, and disaster recovery
- Enterprise desktop
  Secures unmanaged PC's and laptops via software
