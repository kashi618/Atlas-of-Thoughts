## Coupon Book
An app that lets users store Dunnes Stores discount codes. The system pools them together so everyone can use them. For example, if you have a discount that expires in a week but won't use it, you can add it to the app so someone else can use it. In return, you earn a point for the discount, which you can later use to redeem a coupon. The more codes you share, the more points you earn, encouraging people to keep contributing and keeping the pool of available discounts fresh and useful for everyone. Since coupons expire, we could also introduce a system where users who give the most coupons get higher priority to receive a free coupon.

## Cat Treat Tracker
Available as both a mobile app and a web browser app.
Lets you see when you have given your greedy cat a treat, so you don’t overfeed her. Supports notifications to show that she has been fed a treat. Should be easy to use and very simple. Could be locally hosted, but this would require 24/7 uptime. Maybe use a cloud server instead.

## Day Trip Planner
Plan a trip from point A to point B. Using Google Maps as the backend, it would find events, fun spots, and activities along the way. The trip would be customisable: you could set a maximum transport time, limit the maximum detour distance/length, sort activities by rating, and more.

Possible additions:
- Let users add their own places for hidden gems not available on Google Maps, Yelp, Eventbrite, etc.
- Include concerts.
